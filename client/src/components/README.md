# Shared components

`Layout`, `Call1122Bar`, `Button`, `TextField`, `WarningBox` and the loading/placeholder
pages here are **stand-ins** so the auth screens could be built (PLAN.md §3:
"until a hand-off is ready, mock it"). Person 1 owns the shared layout and can
replace them; keep the props the same, or update the auth screens with them.
All values come from Style sheet v1 via the CSS variables in `index.css`.
