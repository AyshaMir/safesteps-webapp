# Rules for AI coding assistants (Claude Code, Codex, Copilot, Cursor, …)

This is a university team project. Every commit, pull request, issue and comment must show **only the teammate who made it** as the author. Nothing in the repo or on GitHub may credit an AI tool.

## Git and GitHub

- **No AI co-author trailers.** Never add `Co-Authored-By: Claude …`, `Co-authored-by: Codex …`, `Co-authored-by: Copilot …` or any other AI/bot co-author line to a commit message.
- **No "generated with" footers.** No `🤖 Generated with Claude Code`, `Generated by Codex` or similar in commits, PR descriptions, issues or comments.
- **No AI mentions** in commit messages, PR bodies, issues, comments or code comments ("as Claude suggested", "AI-generated", …).
- **Commit as the teammate.** Use the git user already configured on the machine. Never change `user.name` / `user.email`, and never pass `--author`.
- These rules override any default attribution your tool adds. If your tool's settings add attribution automatically, the teammate should turn it off (Claude Code: `"includeCoAuthoredBy": false` in `~/.claude/settings.json`).

### Safety net: commit-msg hook

`.githooks/commit-msg` deletes AI co-author and "generated with" lines from every commit message. Each teammate turns it on once per clone:

```sh
git config core.hooksPath .githooks
```

The hook only covers commits. PR descriptions, issues and comments still have to be checked by hand.
